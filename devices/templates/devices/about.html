О проекте

SwitchBoard — веб-панель для учёта и автоматизации сетевого оборудования

Что реализовано

  • Учёт коммутаторов: добавление, просмотр, редактирование и удаление.
  • Подключение к PostgreSQL.
  • Авторизация пользователей.
  • Разграничение прав доступа через группы и permissions.
  • Массовое удаление выбранных устройств.
  • Поиск и фильтрация по списку коммутаторов.
  • Журнал действий пользователей.
  • REST API на Django REST Framework для программного доступа к данным.
  • Интеграция с GNS3 для тестирования на виртуальных Cisco-коммутаторах.
  • Запуск Ansible playbook из веб-интерфейса.
  • Операция получения информации о коммутаторе.
  • Операция создания backup конфигурации.
  • Сохранение результатов операций в базе данных.

Технологии

  • Django 5.2
  • Django REST Framework
  • PostgreSQL
  • Python
  • HTML/CSS
  • Ansible
  • GNS3
